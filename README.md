## Insider Threat Detection Using Machine Learning Models

This repository presents a hybrid approach to insider threat detection that integrates:
- Unsupervised anomaly detection via **Autoencoder, LSTM, Decision tree, Ensamble Method**
- Semantic and behavioral reasoning using **Large Language Models**
- Attacks using SMTP servers

### Experimental Data
Experiments were conducted using the **CERT Insider Threat Dataset**:
- **Release R4.1**: Model training
- **Release R4.2**: Model testing and evaluation

Dataset available at:  
https://kilthub.cmu.edu/articles/dataset/Insider_Threat_Test_Dataset/12841247
